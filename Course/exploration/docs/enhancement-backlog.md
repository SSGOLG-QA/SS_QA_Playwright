## P0 — 즉시(높은 효과·낮은 위험)

### B1. 행 선택 선행조건 처리 — ⚠️ 효과 없음(2026-09-17 라이브): 이 화면군 무효
- **라이브 결과**: 전 리스트 `선행 행선택=X(no-checkbox)` — 그리드에 행 체크박스 없음, [보기]는 행 액션 버튼이라 선택 선행조건 불필요. B1 미발동. 작업지시/이슈 [보기] 변동성은 **환경/데이터 의존**(재현기가 FLAKY로 처리). **→ B1 폐기 또는 '행 스코프 [보기] 클릭'으로 교체(후순위).**
- **구현(남김)**: `transitions.selectFirstRow`(체크박스/라디오 클릭) + `VIEW_TRIGGER`. 체크박스 있는 화면에선 여전히 유효.
- **근거(런 데이터)**:
  - `이슈 관리 [보기]` → **무동작 관찰**(전이 확장 1/2, "클릭 후 전환 없음 — 게이트/선행조건 의심").
  - `작업 지시 [보기]` → **JS 예외** `Cannot set properties of undefined (setting 'isError')`, 모달이 **액션 0개**로 열림(F001).
  - 공통 가설: **리스트 행을 선택하지 않은 채 [보기]** → 무동작(이슈) 또는 미처리 예외(작업지시).
- **개선안**: `transitions`에 `selectFirstRow(admin)` 추가 — 뷰형 트리거(`보기/상세/수정`) 실행 **전** tbody 첫 행(체크박스/행 클릭)을 선택. openTrigger에 `requireRow?: boolean` 옵션.
- **예상효과**: ① 이슈 [보기]가 실제 상세로 전이(깊이↑) ② 작업지시 [보기] 예외가 **"무선택 방어 실패"(진짜 결함)** vs **"정상경로 예외"** 로 판별 — 현재는 원인 불명.
- **위험**: 비파괴(행 선택은 조회). 난이도 중.

### B2. netfault 라이브 검증 — ✅ 완료(2026-09-17) + 오라클 정밀화
- **라이브 결과**: 이슈/발병/장비/자재=resilient(적용/검색 시 500 정상처리)·작업지시=FLAKY(후보 제외 정상)·코스기본정보=REPRODUCIBLE(단 reload로 7개 API 전면 주입 = **과광범위 아티팩트**).
- **정밀화 반영(F1)**: `netfault.INFRA_RE`로 부팅 인프라(lang/messages·i18n·auth·menu·common/config·권한) **주입 제외** → 셸은 살고 화면 데이터만 장애. 주입 URL을 evidence에 `대상[...]` 표기. 코스기본정보 전면outage 아티팩트 제거·단일화면 장애처리 검증으로 전환. **재검증 필요.**
- **근거**: `코스 기본 정보` = **열기형 트리거 0**(액션후보 2: 이용가이드·수정) → 현재 탐색이 **아무것도 못 함**. 조회전용 화면은 트리거 탐색보다 **API 장애 복원력**이 맞는 축. netfault는 구현됐으나 **미실행**.
- **개선안**: 코드 변경 없음 — `$env:EXPLORE_NETFAULT="1"; npm run course:explore` 라이브 실행 후 판독.
- **예상효과**: 6개 화면(특히 조회전용)에서 5xx 주입 시 uncaught 예외/무음 백지 실측. 판독으로 오라클(refetch 트리거 탐지·백지 임계) 튜닝.
- **위험**: 비파괴(서버 불변). 난이도 소.
