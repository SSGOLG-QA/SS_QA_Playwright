# 자동화 검증 표준 (Comprehensive · System-Agnostic)

> UI 검증 자동화 프로젝트에서 구축·검증된 **전 검증 층위·원칙·커버리지 모델**을 도구/시스템 무관 표준으로 통합.
> 근거: td17 경기관제 어드민 + course-mng-td 코스관리 자동화(검증 층위 13종·다국어 7개국·폼 E2E 17화면·이력 대시보드). 타 시스템 이식 시 이 표준을 적용.
> 구성: **Part I 원칙 · II 검증 층위 · III 커버리지 모델 · IV 실행 기준 · V 리포팅/회귀 · VI 착수 체크리스트**.

---

# Part I — 원칙 (4개 기둥 + 세부)

| 기둥 | 정의 |
|------|------|
| **전수 검증(fail-continue)** | 실패해도 throw 없이 기록 후 계속 → 한 런에 전 항목 결과 |
| **비파괴(non-destructive)** | 데이터 변경은 노출·활성만 또는 원복. 저장/삭제 미실행 |
| **AS-IS 기준** | 구현이 기획과 달라도 기능 정상이면 기대값을 구현에 맞춤 |
| **커버리지 투명성** | 미검증(SKIP)을 사유와 함께 가시화 |

### 1. 비파괴
편집은 **폼 진입 → 조작 → 취소/뒤로가기 폐기**(submit 미클릭). 삭제·업로드는 **자체 생성분만**. 토글은 원복. 진짜 파괴 테스트는 **옵트인 가드 + teardown 원복**.

### 2. 2축 검증
구현≠기획이나 기능 정상 → **검증축**(기대값 AS-IS로, 가짜 FAIL 제거) + **추적축**(차이를 `diff()`로 별도 기록).

### 3. 무오탐 적응형 판정
"동작 안 함"을 4-way 분류: ①비활성 ②안내/토스트(제한·검증) → **SKIP+diff** / ③스코프·카운트(테스트측) → **SKIP** / ④전부 무변화·안내없음 → **FAIL**. 데이터 부재도 SKIP.

### 4. 커버리지 투명성
SKIP은 사유 필수. "폼/기능 없는 화면"은 프로브로 **read-only 확정** → 갭 아님(분모 분리).

# Part II — 검증 층위 (Verification Layers)

자동화는 단일 축이 아니라 **층위의 스택**이다. 화면마다 아래 층위를 데이터·성격에 맞게 쌓는다.

| # | 층위 | 목적 | 방법 | 판정 |
|---|------|------|------|------|
| L1 | **구조 (Structural)** | 요소·컬럼·버튼·탭·섹션 노출·활성 | `check` + `toBeVisible`/`toHaveCount`(컨테이너 스코프) | PASS/FAIL |
| L2 | **문구 (Textual)** | 안내문구 TC 원문 일치 | `checkText`(공백 단일화, 띄어쓰기까지) | 문구 불일치 FAIL |
| L3 | **RAW/오타** | 미가공 코드·i18n 키 누출(`ui.2971`)·오타 | `checkRawCode`(진입 화면마다 자동) | 검출 시 기록 |
| L4 | **행 정합성** | 총 건수 = 렌더 행 수 | `checkRowCountVsTotal` | 불일치 FAIL |
| L5 | **불변식 (Calc Invariants)** | 파생값 재계산: 합계=Σ·총=남+여·순위 연속·평균=mean·가중치 합=100·비율∈[0,100] | 순수 도메인 함수로 UI값 재계산·대조 | 불일치 FAIL/diff |
| L6 | **상호작용 E2E** | 폼 배터리(입력·클리어·추가/삭제·datepicker·파일)·Write-path(등록→확인→삭제)·팝업 딥 인터랙션 | 비파괴 조작 → 취소/원복 | PASS/SKIP |
| L7 | **IA 구현여부** | 전 메뉴 구현/미구현 | IA_TREE 순회, navigate 성공=구현 | 구현/미구현 |
| L8 | **다국어 (i18n)** | 7개국 정적 UI 표기 결함 | KO baseline 슬롯 ↔ 언어전환 후 대조(구조적 DOM 경로 키) | 6분류(하단) |
| L9 | **토스트/에러 i18n** | 실변경 제출 토스트 번역 | `MutationObserver` 사전 설치 → 제출 → 분류 | 언어 분류 |
| L10 | **API 계약** | 응답 상태·타입·에러 envelope | 상태 2xx·CT JSON·파싱·`success:false`/`error`/`code≥400` 미포함·키/countPath | 위반 FAIL |
| L11 | **UI 구조 드리프트** | 구현 변경(요소 제거/추가) 자동 감지 | committed baseline 스냅샷 대조 | 제거=FAIL·추가=diff·소실=FAIL·신규=diff |
| L12 | **시각 회귀** | 글리프 깨짐·글자 잘림·아이콘 누락·레이아웃 붕괴(DOM·i18n 범위 밖) | `toHaveScreenshot` 픽셀 대조(고정 뷰포트·동적 마스킹·maxDiffRatio) | 픽셀 초과 FAIL |
| L13 | **파괴 테스트 (gated)** | 저장/삭제/CRUD 실동작 | `ALLOW_DESTRUCTIVE=1` + 호스트/테넌트 화이트리스트, `withFixture` teardown 원복 | PASS/SKIP |
| L14 | **단언 민감도 (Meta)** | 단언이 변조를 잡는가(검증의 검증) | DOM 결함 주입 PoC + 정적 단언 감사기 | 민감/둔감 |

### L8 다국어 6분류 (결함 카테고리)
`① 한글 노출(전환 후 잔존) · ② 언어 혼재(한글+타스크립트) · ③ 미번역(빈값) · ④ 인코딩 깨짐(`�`·`□`·`??`) · ⑤ 글자 잘림(leaf overflow) · ⑥ 타 언어 노출(대상 아닌 외국어)`. **PASS=정상 번역 항목을 실제 번역값과 함께 전수 기록**. 시스템 요소만(컨텐츠 데이터 배제). 종료 전 원복(비파괴).

### 층위 선택 규칙
- **모든 화면**: L1·L2·L3·L7(자동).
- **리스트/총계 화면**: +L4·L5.
- **폼 보유 화면**: +L6.
- **전 화면(별도 런)**: L8/L9(i18n)·L10(API)·L11(드리프트)·L12(시각).
- **테스트 환경·비실데이터**: L13(gated).
- **주기적**: L14로 단언 품질 감사.

# Part III — 커버리지 모델 (다축 측정)

커버리지는 "화면 수" 하나가 아니라 **5축**으로 측정한다. 한 축만 높으면 착시.

### 축 A — 화면 커버리지 (Breadth)
`검증 화면 / IA 전체 소메뉴`. read-only·미구현은 프로브로 확정해 **분모에서 분리**(폼/기능 없는 화면을 갭으로 오계상 금지).

### 축 B — 층위 커버리지 (Depth)
화면별로 어느 층위까지 쌓였나(구조만? 불변식까지? i18n까지?). **층위 매트릭스**(행=화면, 열=L1~L14)로 깊이 시각화. "구조만 PASS"는 얕은 커버리지.

### 축 C — 단언 품질 (Sensitivity)
느슨한 단언(부분일치·`count≥1`·존재만)은 **둔감** → 변조를 놓침. L14 감사기로 민감/둔감 측정. 커버리지 100%라도 둔감하면 무의미.

### 축 D — SKIP 투명도
SKIP 사유 4분류: `LEGIT(의도적 비검증)·DATA(데이터 부재=잠재 갭)·ENV(진입/전환 실패)·미구현`. **DATA 집중처**가 진짜 커버리지 구멍. 정적 감사기로 집계.

### 축 E — 회귀 이력 (Trend)
실행마다 DB append(run/menu별 PASS/FAIL/SKIP) → 트렌드 대시보드. 단발 100%가 아니라 **시간축 안정성**이 신뢰의 근거.

> **표준 커버리지 리포트** = A(화면 %) + B(층위 매트릭스) + C(민감도) + D(SKIP 분류) + E(트렌드). 5축을 한 장에.

# Part IV — 실행 기준

### 워크플로 — 프로브 우선
`① 분석(프로브: 실 DOM 캡처) → ② 문서(locator) → ③ 스위트(run*) → ④ 스펙 → ⑤ 실행 → ⑥ 리포트`. **셀렉터·기대값 추측 금지.** 프로브 1회 < 재실행 N회.

### 셀렉터 기준
동적 채번 ID 금지 · 컨테이너/섹션 스코프 · 구조적 DOM 경로(`nth-of-type` 체인) · 텍스트·role 우선 · 공백/맞춤법 정규식 · 아이콘 버튼은 클래스/`title` · 데이터 값 `≥N`(고정 count 금지).

### 프레임워크(Vue/React) 대응
비동기 모델 반영 → **2-phase**(클릭 → nextTick 대기 → 재조회). 완강한 위젯 → **네이티브 dispatch**(매번 in-page 재선택 + pointer/mouse/click). 가시성 = `getBoundingClientRect()>1`(**offsetParent 금지**, fixed 모달서 null).

### 폼 진입점 5형태
①모달 ②페이지(저장) ③페이지(취소로 판정) ④라우트 이동(/reg·edit) ⑤인라인(저장 상주). 비표준 라벨은 프로브 규명 후 정규식 확장.

### 환경 · 세션
세션 1런/로그인 → **단일 test 전 화면 순회** · 만료 위장 → **degraded 가드**(로그인 페이지 감지) · 재인증 후 **storageState mtime 확인** · 무거운/상태파괴 화면 → **격리 스펙**(신선 세션 1개) · 진입 플레이크 → retries+렌더 대기 · 병렬은 계정 풀(distinct 계정).

# Part V — 리포팅 · 회귀

- **리포터 패턴**: `check`/`checkText`/`checkRawCode`/`checkRowCountVsTotal`/`skip`(사유)/`diff`(기획-구현)/`recordIA`/`noTC`. **throw 안 함**.
- **메타**: `{path, tcRef(원본 TC키), tcId, desc, expected?, failMsg}`.
- **산출 시트**: 요약 대시보드(진행률·PASS/Fail rate) · 대메뉴별 · IA · SKIP 감사 · 기획-구현 차이 · 화면별 커버리지.
- **이력 DB**: 실행마다 append → 트렌드 대시보드(회귀 조기 감지, 색상 임계 90/70%).
- **드리프트 감시 루프**: `전수 실행 → FAIL/SKIP 산발 → 개별·직렬 재실행(플레이크 제거) → 프로브 덤프 → 기대값 AS-IS 갱신 + diff`.

# Part VI — 신규 시스템 착수 체크리스트

```
── 기반 ──────────────────────────────────
[ ] 인증 브릿지(storageState 재사용 + 만료 fail-fast + mtime 확인)
[ ] IA 트리 실측 → 화면 목록·라우트 확정
[ ] 프로브 1종 → 대표 화면 DOM 캡처(analysis/*.json)
[ ] 공용 헬퍼(openAdmin·gotoMenu·settle·killOverlays·extractDom)
[ ] 리포터 + 이력 DB + 커버리지 측정 편입
── 층위 구축(화면 성격별) ────────────────
[ ] L1 구조 · L2 문구 · L3 RAW · L7 IA (전 화면 자동)
[ ] L4 정합성 · L5 불변식 (리스트/총계 화면)
[ ] L6 상호작용 E2E (폼 보유 화면 — 진입점 5형태)
[ ] L8/L9 다국어 (지원 언어 × 전 화면, 별도 런)
[ ] L10 API 계약 · L11 드리프트 baseline · L12 시각 회귀
[ ] L13 파괴(테스트환경·옵트인) · L14 단언 민감도 감사
── 커버리지·운영 ─────────────────────────
[ ] read-only 화면 프로브 확정 → 분모 정리
[ ] 5축 커버리지 리포트(화면·층위·민감도·SKIP·트렌드)
[ ] baseline 캡처 → 드리프트 감시 루프 가동
```

## 부록 — 반복 관통 교훈 Top 12
1. **프로브 1회 > 재실행 N회** — 셀렉터 추측은 반드시 재작업.
2. **가짜 FAIL이 진짜 FAIL을 가린다** — AS-IS + 무오탐 4-way 분류.
3. **커버리지는 5축** — 화면 수만 보면 착시(층위·민감도·SKIP·트렌드).
4. **느슨한 단언은 둔감** — 존재/부분일치는 변조를 놓침 → 전문일치·불변식·컬럼 정확일치.
5. **SKIP=미검증** — 사유 분류(LEGIT/DATA/ENV/미구현), DATA가 진짜 갭.
6. **비파괴는 취소로 완성** — 편집→취소/goBack, 자체 생성분만 삭제.
7. **비동기 read는 2-phase** — nextTick 대기 필수.
8. **offsetParent 금지 · 동적 ID 금지** — rect 가시성·컨테이너 스코프.
9. **무거운/상태파괴 화면은 격리** — 한 런에 2개 불가.
10. **세션 만료는 로그인 페이지로 위장** — degraded 가드.
11. **read-only 확정도 커버리지** — "기능 없음" 증명 = 갭 아님.
12. **층위는 데이터로 산다** — 정합성·불변식·i18n은 실데이터 없으면 SKIP, 있을 때만 진가.
