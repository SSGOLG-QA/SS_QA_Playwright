## 4. 스코어/결과집계 팝업 (새 탭 풀페이지·읽기전용) — ✨2026-06-29
> td8 [스코어]·td10 [결과집계/출력] 클릭 시 **같은 컨텍스트 새 탭**으로 풀페이지 랜딩(모달 아님). 데이터 의존(라운드종료 행 우선).
> 🔴 **비파괴**: 새 탭은 **읽기만 후 닫기**. 팝업 내 [수정하기]/[스코어 수정]/[상세 스코어 추가]/[인쇄]/[순위·시상 편집] **절대 클릭 금지**.
> 구현: `runGroupRoundPopups`(suites.ts) + 순수 불변식 `lib/domain/groupRound.ts`. 진단 프로브 `Admin/_probe-group-round-newtab.spec.ts`.

### ① 스코어 팝업 — `/club/RoundGroupScore/{roundGroupId}`
- 헤더: 단체명·행사일자·참가자수 / 버튼 [인쇄][수정하기][총타수로 표시][오버타수로 표시] / 정렬 [전체 그룹][스코어순(좋은순)]
- **스코어카드 테이블**(클래스 없음): `Player · Tee · Course · 1~9(전반홀) · 전반 · 1~9(후반홀) · 후반 · 합계 · 오버타수 합계`
  - 추출: 헤더 공백제거 후 `전반`/`후반`/`합계`/`오버` 인덱스로 컬럼 위치 확정(홀별 1~9는 데이터 미입력 시 공란).
- **정합성 불변식**(`groupScoreInvariants`):
  - `합계 = 전반 + 후반` (예 여2: 38+42=80)
  - `합계 − 오버타수 = Par(전 플레이어 일정, 킹즈락 72)` (80−8 = 109−37 = 72)
  - `합계 ≥ 0`

### ② 결과집계/출력 팝업 — `/club/RoundGroupRank/{roundGroupId}`
- 헤더: 단체명·행사일자·참가자수 / 버튼 [인쇄][스코어 수정][상세 스코어 추가] / 그룹 탭 [전체 그룹][여성팀][남성팀]
- 영역: **순위/시상 설정 및 편집** → **시상내역**(최우수/은/동메달·핸디상·신페리오·다버디/다파/다보기 등) / **Team Average**(전체·남자·여자 평균) / **라운드 주요 기록 별 순위** 테이블
- **순위 테이블** 핵심 컬럼(content 휴리스틱 추출): `순위(td0) · 성별 M/F(첫 4칸 중) · 이름 · 스코어(gross)`
- **정합성 불변식**:
  - 순위 `1..N 연속` (`rankOrderInvariants`)
  - 스코어 `단조 비감소`(상위 순위=저타수, 좋은순)
  - Team Average: `전체평균 = mean(전원)` · `남자평균 = mean(남자)` · `여자평균 = mean(여자)` (소수 1자리, `teamAvgInvariants`) — 예 (80+83+99+109)/4=92.75→92.8 ✓
  - 시상 `최우수상 점수 = 최저 스코어 = 1위` (body 텍스트 `최우수상 {이름} {점수}` 파싱)
  - 교차정합: `결과집계 순위표 스코어 = 스코어 팝업 합계`(이름 조인)

> ⚠ 정합성은 **라운드종료(데이터 완비) 행** 기준. 데이터 없거나 새 탭 미발생(window.open 차단) 시 해당 GRND는 `skip`(가짜 FAIL 방지).
